## 💡 为什么做这个项目？(项目初衷)

> **“秋招刷力扣真的很让人崩溃……”**

如果你也正在经历**秋招 / 春招 / 实习求职**，你一定懂这种无力和挫败感：
- 🤯 **题解太晦涩**：市面上官方和高赞题解往往直接甩出一堆生硬的专业术语和一行毫无过渡的状态转移方程，默认你全懂，根本不讲清楚*“到底是怎么一步步想出来的”*。
- 📉 **缺乏正向反馈**：死记硬背把代码抄了一遍，点了力扣的提交通过，但过两天换个马甲又完全不会写，做题只有焦虑，没有踏实感。
- ⏳ **复习无从下手**：二元化的“已完成/未完成”根本无法衡量真实的掌握度，临近面试到底该复习哪一道、重点看哪个陷阱？

**我渴望有一个能用 AI「大白话」像贴心学长一样在耳边把每道题讲通讲透的系统。**  
于是我做了这个 **Hot100 原子化突破体系** —— 不再死记硬背几百行冷冰冰的代码，而是将每道题拆解为环环相扣的**原子检查点**，配合大白话思路拆解与可视化修行日历，陪你把力扣 Hot 100 真正吃透、拿下心仪 Offer！

## 🌟 核心特色与功能

### 1. 🗣️ AI 大白话精讲：像私教一样讲透核心逻辑
- **通俗比喻代替数学行话**：双指针是“一快一慢的探子巡逻”，滑动窗口是“会伸缩捕食的毛毛虫”，单调栈是“排队找右边第一个比自己高的人”。
- **逐行代码互动解析**：点击检查点即可展开查看对应代码段落的保姆级注释与设计缘由，初学者也能看懂每一步为什么这样写。
- **高频基础函数反复强化**：不回避重复基础知识，重点语法、指针操作与高频 API 多次穿插讲解，温故知新。

### 2. 🎯 动态原子微检查点 (Micro-Checkpoints)
拒绝简单的“已做 / 未做”二元标签，针对每道题目的深度和难点差异，量身定制检查点：
- 🎯 **破题眼 (Pattern Recognition)**：一眼识别考点（“看到有序数组找目标值，先想双指针/二分”）。
- 🛡️ **边界防守 (Corner Cases)**：避坑指南，空数组、单元素、越界溢出提前防守。
- ✍️ **核心实现 (Optimal Code)**：大白话注释的最优解范式，逻辑纯粹无多余枝节。
- ⏱️ **时空演练 (Complexity & Tradeoff)**：面试时如何自然向面试官表达时间和空间复杂度。

### 3. 🔥 做题修行热力图日历 (Activity Heatmap)
- **GitHub / LeetCode 风格 26 周贡献矩阵**：记录你近半年（182天）的每一分努力。
- **动态修行勋章与指标统计**：实时追踪 **当前连续打卡（Current Streak）**、**最长连续天数** 与 **累计修行天数**。
- **5 级翡翠绿成就阶梯**：打卡越多颜色越明亮，悬停可查看每日检查点达成明细，提供满满的秋招成就感。

### 4. 🌗 极简精致 UI & 渐进深浅色模式
- 遵循极简高级审美设计，杜绝臃肿信息干扰。
- **一键切换夜间/日间模式**：暗色模式采用柔和 Slate-950 背景，熬夜刷题不眩光、不伤眼。
- **全屏原生 Markdown 题面**：支持数学公式、代码块、引用块与样例的高保真清晰渲染。

### 5. 🔒 纯本地数据隔离 & 一键备份迁移
- **100% 客户端私密**：默认基于浏览器 LocalStorage，每个人的刷题进度完全属于自己，彼此零串扰、永久保存无过期限制。
- **双重灾备与迁移**：提供 **【导出备份】** 与 **【导入恢复】** 功能，一键生成 `.json` 文件，换电脑或多设备切换随时无缝还原。

## 📅 7天专题冲刺路线图 (7-Day Sprint Roadmap)

| 天数 | 核心专题 | 涵盖题量 | 典型题型与考点 |
| :--- | :--- | :---: | :--- |
| **Day 1** | 哈希表、双指针与滑动窗口 | 17 题 | 两数之和、无重复字符的最长子串、三数之和、接雨水 |
| **Day 2** | 矩阵技巧与链表全解 | 18 题 | 旋转图像、反转链表、K个一组翻转、LRU 缓存机制 |
| **Day 3** | 二叉树与图论搜索遍历 | 19 题 | 二叉树层序遍历、最近公共祖先、岛屿数量、课程表 |
| **Day 4** | 回溯算法与二分查找 | 14 题 | 全排列、子集、括号生成、寻找旋转排序数组中的最小值 |
| **Day 5** | 栈、堆与贪心思维 | 12 题 | 有效的括号、最小栈、前 K 个高频元素、跳跃游戏 |
| **Day 6** | 动态规划一维经典核心 | 10 题 | 爬楼梯、打家劫舍、零钱兑换、最长递增子序列 |
| **Day 7** | 多维动态规划与高频技巧 | 10 题 | 最小路径和、最长公共子序列、编辑距离、只出现一次的数字 |

## 🚀 极速使用指南

### 方式一：线上即开即用（最推荐 ⚡）
直接用浏览器打开：
👉 **[https://junior-hot100.vercel.app/](https://junior-hot100.vercel.app/)**  
手机端、平板、电脑端均已完成自适应，收藏到书签即可随时随地刷题打卡！

---

### 方式二：本地双击一键启动 (Windows)
如果想要离线在本地运行并把数据存在本地 SQLite 数据库中：
1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/huh7i5/junior-hot100.git
   cd junior-hot100
   ```
2. 直接双击运行根目录下的：
   ```bash
   start.bat
   ```
   系统将自动启动后端服务并在默认浏览器打开：`http://127.0.0.1:8765`。

---

### 方式三：开发者二次开发与构建
```bash
# 1. 进入前端目录开发
cd frontend
npm install
npm run dev      # 启动 Vite 热更新服务 (默认端口 5173，自动代理 /api)

# 2. 生产环境打包构建
npm run build    # 产物自动输出至 dist/，供 Vercel 或 FastAPI 静态托管

# 3. 运行本地 Python API 后端 (可选)
cd ../backend
python server.py # 启动 FastAPI 服务 (端口 8765)
```
